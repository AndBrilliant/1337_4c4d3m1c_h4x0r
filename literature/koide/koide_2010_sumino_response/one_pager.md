# Koide 2010 — Scalar-potential model stimulated by Sumino (Sumino relation)

## Reference
Y. Koide, **arXiv:1004.0580** → ***Phys. Lett. B* **687** (2010) 219**.

## Source
Both Koide literature review research reports, §1 / §A.

## Beyond-abstract summary
Koide's response to Sumino's family-gauge mechanism (Sumino 2008, arXiv:0812.2090). Constructs a scalar-potential model **stimulated by Sumino** and predicts the **"Sumino relation"** m_μ^(3/2) + √(m_e m_μ m_τ) = √(m_e m_τ)(√m_e+√m_τ), which is implied by Sumino's setup but had not been previously recognised as a separate empirical constraint. Marks the start of the period in which Koide's program engages directly with Sumino's mechanism.
