# Krolikowski 2005b — Koide + sum-rule overdetermined system

## Reference

## Beyond-abstract summary
Combines the Koide relation with a *second* mass sum rule to over-determine the masses. The overdetermined system is then used to make additional predictions. Counted among the Koide extension attempts to constrain mass spectra further.

## Sections / contents

- Second sum rule (chosen for compatibility with Krolikowski's preferred mass-matrix framework).
